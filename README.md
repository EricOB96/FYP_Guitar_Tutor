# FYP_Guitar_Tutor

https://youtube.com/shorts/hV5oY7GmVQ4

 An augmented reality  guitar learning application that combines real-time guitar tuning with interactive scale intruction. Built as a final year projct for Computer Science Degree, this app provides an immersive learning experience for beginner guitarists.

![Screenshot 2025-04-15 184343](https://github.com/user-attachments/assets/05550a66-f817-40af-a027-647d5d77bda8)


# Features
- Realtime tuning for standard tuning (E A D G B E)
- Visual feedback with AR overlay
- Audio analysis using YIN alogrithm for pitch detection

- Language: c#
